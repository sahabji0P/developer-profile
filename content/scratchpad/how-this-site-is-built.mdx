This site is my portfolio. Posts live as MDX files; the page is a reading column, not a dashboard.

- Next.js App Router
- TypeScript
- Tailwind v4
- next-mdx-remote + gray-matter
- Iowan Old Style / Palatino / Georgia stack
- measure 600px
- dark only (`#1b1a19` ground, `#e8e5df` copy)
- accent `#2DD4BF`

The layout and type follow [leerob.com](https://leerob.com) (dark tokens from the live site). The MDX pipeline is sketched from [leerob/next-mdx-blog](https://github.com/leerob/next-mdx-blog).
