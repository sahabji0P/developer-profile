This site is my portfolio. Posts live as MDX files; the page is a reading column, not a dashboard.

- Next.js App Router
- TypeScript
- Tailwind v4
- next-mdx-remote + gray-matter
- Geist Sans (UI / titles) + EB Garamond (body) + Geist Mono
- measure 600px
- cream ground `#f7f7f4`, charcoal `#26251e`
- accent `#f54e00`

Type and color take cues from [cursor.com](https://cursor.com). Layout measure and MDX pipeline still follow patterns from [leerob.com](https://leerob.com) / [leerob/next-mdx-blog](https://github.com/leerob/next-mdx-blog).
