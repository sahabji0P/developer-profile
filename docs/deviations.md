# Intentional deviations

Anything **not** listed here should still match the portfolio brief (routes, content, 600px column, vertical text nav, no hamburger).

## Cursor-inspired theme (requested)

Live [cursor.com](https://cursor.com) (measured 2026-09-13) uses cream `#f7f7f4`, charcoal `#26251e`, accent `#f54e00`, **CursorGothic** for UI, **EB Garamond** for body, **Berkeley Mono** for code.

We approximate that with public fonts:

- **Geist Sans** → CursorGothic stand-in (titles, nav, section heads, dates)
- **EB Garamond** → same body face Cursor ships
- **Geist Mono** → Berkeley Mono stand-in
- Accent **`#f54e00`**, ground **`#f7f7f4`**

This replaces the earlier dark leerob-token pass after explicit preference for Cursor theming/fonts.

## Nav + footer

Still product requirements (Cursor marketing uses a top bar; we keep the brief’s top-right vertical text stack / in-flow mobile row, plus footer contact).

## Routes + content

Unchanged from the brief: `/`, `/work`, `/about`, `/blog`, `/scratchpad`, RSS, llms.txt, three-line home bio, Selected work / Writing / Scratchpad.

## No collage / no product chrome

We do not copy Cursor’s hero painting, pill CTAs, or desktop mockups — only the type/color atmosphere on a reading-site structure.
